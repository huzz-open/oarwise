# Oarwise 行舟

让 Codex、DSH 在指定 Windows 窗口中截图、点击和输入，协助完成电脑操作。

[官网](https://oarwise.com) · [账号与下载](https://oarwise.com/account) · [安装指南](docs/installation.md) · [问题反馈](https://github.com/huzz-open/oarwise/issues/new/choose)

## 1. 可以做什么

- 发现并绑定指定程序窗口。
- 获取完整或局部截图，导出图片供 AI 查看。
- 在后台点击、输入文字、按键、滚动和拖拽。
- 在兼容应用中对最小化窗口继续操作。
- 按聊天会话管理资源，结束或取消时清理。

适用于 Windows，接入 Codex 与 DSH。具体应用的截图、输入和最小化能力需要实际验证。

## 2. 安装与激活

1. 从官网购买入口或已对接渠道取得注册码。
2. 在官网用邮箱和注册码激活账号，已有账号在个人信息页兑换。
3. 下载对应客户端的加密 ZIP。完成邮箱验证且权益有效后，账号邮箱会收到安装说明和解压密码。
4. 用 7-Zip 解压。Codex 将解压目录作为本地插件市场添加，DSH 安装解压得到的 TGZ。
5. 按插件提示确认连接当前电脑。

[详细安装步骤](docs/installation.md) · [账号和设备管理](docs/account.md)

## 3. 发行包

[GitHub Releases](https://github.com/huzz-open/oarwise/releases) 提供加密发行包和 SHA-256 校验值。使用密码解压后仍需账号和设备授权。密码按发行版本维护，遗失时可在官网个人信息页重新发送到账号邮箱。

每个版本的改动和对应文件请查看 Releases。
