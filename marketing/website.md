# 官网产品说明

## 1. 产品名称

Oarwise 行舟，AI 后台电脑操作插件。

## 2. 产品介绍

让 Codex、DSH 在指定 Windows 窗口中截图、点击和输入。AI 可以观察目标界面、执行用户安排的操作并核对结果，用户可以继续使用其他窗口。

## 3. 功能要点

- 后台截图与局部查看。
- 点击、文字输入、按键、滚轮和拖拽。
- 兼容应用的最小化操作。
- 官网统一管理账号权益和设备。
- 邮箱交付解压密码，个人信息页提供安装包下载。

## 4. 页面入口

[官网](https://oarwise.com) · [个人信息](https://oarwise.com/account) · [安装指南](../docs/installation.md) · [用户反馈](https://github.com/huzz-open/oarwise/issues)

页面内容和当前售价以官网显示为准。产品兼容性以实际应用验证结果为准。
