# 常见问题

## 1. 安装包为什么需要密码

发行包使用 AES-256 加密 ZIP，密码通过权益账号的邮箱交付。请使用 7-Zip 解压，并确认邮件版本与包版本相同。

## 2. 为什么密码正确仍无法使用插件

解压和运行授权是两个步骤。安装后需按提示登录并确认连接这台电脑。可在官网个人信息页查看权益和设备名额。

## 3. 是否包含 AI 订阅

产品提供 Windows 后台观察与输入能力。Codex、DSH 等客户端需要的 AI 订阅、API 额度及其他软件账号由用户准备。

## 4. 是否支持所有应用

目标应用的渲染方式、权限和输入实现会影响兼容性。最小化操作也取决于目标应用。问题反馈请注明应用、系统和插件版本以及复现步骤。

## 5. 如何更新

从个人信息页下载新版，使用对应版本密码解压，再通过客户端插件管理更新。Codex 更新本地市场路径后需重新安装插件。新建聊天确认加载的插件版本。
