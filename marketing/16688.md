# 16688 商品说明

## 1. 商品用途

Oarwise 行舟为 Codex、DSH 等 AI 客户端提供 Windows 后台截图、点击和输入能力。购买内容为行舟账号权益注册码，AI 客户端订阅及 API 额度由用户自行准备。

## 2. 套餐入口

| 套餐 | 设备名额 | 商品 |
|---|---|---|
| 一年权益 | 3 台 | [查看商品](https://www.16688.com.cn/goods/G57147143) |
| 三年权益 | 5 台 | [查看商品](https://www.16688.com.cn/goods/G13646313) |
| 永久权益 | 10 台 | [查看商品](https://www.16688.com.cn/goods/G97158429) |

下单前核对商品页价格、购买条件和发货说明。数字注册码的售后条件以商品页面为准。

## 3. 购买后使用

1. 保存收到的注册码和订单号。
2. 到 [行舟官网](https://oarwise.com/account) 使用邮箱完成验证并兑换注册码。
3. 下载对应客户端的加密安装包，从账号邮箱取得对应版本解压密码。
4. 用 7-Zip 解压，按 [安装指南](../docs/installation.md) 安装插件。
5. 确认连接这台电脑，返回客户端检查授权状态。

注册码无效或订单问题通过店铺客服核查。功能使用问题可提交到 [Issues](https://github.com/huzz-open/oarwise/issues/new/choose)。
